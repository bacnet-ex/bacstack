    BACnet.Protocol.ObjectExecution.EventReporting (bacstack v0.1.0-dev.2)

    View Source

    Records event transitions and resolves their notification routing. Updates object properties for an event transition and prepares its delivery information.

    BACnet.Protocol.ObjectExecution.IntrinsicReporting and BACnet.Protocol.ObjectTypes.EventEnrollment call record/5 after evaluating event and fault conditions. The host uses transition/1 on a committed execution result and delivers enabled transitions using their routing plans. If lookup cannot resolve the Notification Class, the transition's routing plan is nil. See BACnet.Protocol.ObjectExecution.Lifecycle for the delivery flow.
