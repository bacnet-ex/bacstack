    BACnet.Protocol.SecureConnect.BVLC (bacstack v0.1.0-dev.2)

    View Source

    Encodes and decodes BACnet Secure Connect Virtual Link Control messages defined in Annex AB. Each WebSocket binary message carries one BVLC message.

    The flags determine which addresses and option lists precede the payload. Link-control messages use the connection peer as the implicit destination. Forwardable messages can carry an explicit destination and receive an originating VMAC as they pass through a hub.

    The codec retains unknown header option types during forwarding. A receiving endpoint checks whether it understands the destination options. A decoding error can carry a partial header so the endpoint can apply the Annex AB rules for returning a BVLC-Result NAK.

    Summary

    Types

    function_name()

    A symbolic Annex AB BVLC function name. Decoded headers for unknown functions can carry the numeric wire code instead.

    option()

    A header option with its numeric type, Must Understand flag, and optional bytes. A nil value means the header data field is absent.

    peer()

    Identity and receive limits advertised by a connection peer.

    t()

    An SC BVLC message before serialization or after decoding. Set an address to nil when the connection peer supplies it. Use empty lists for absent options and an empty binary for a message without a payload.

    vmac()

    A six-octet virtual MAC address. Use valid_vmac?/1 to check a unicast identity and broadcast/0 for the reserved broadcast value.

    Functions

    broadcast()

    Returns the reserved all-ones VMAC used for local broadcasts.

    code(function)

    Returns the wire code for a known BVLC function or an already numeric code.

    decode(binary)

    Parses and validates a complete BVLC message. An error includes the BACnet communication error code and, when the addressing fields were readable, the header needed to determine whether to send a NAK.

    encode(message)

    Serializes the fixed header, selected addresses, option lists, and payload as a binary WebSocket message.

    error_code(name)

    Returns the numeric BACnet error code used in a BVLC Result.

    identity(vmac, uuid)

    Builds the Connect-Request or Connect-Accept payload from a VMAC, device UUID, and the advertised length limits.

    link_function?(function)

    Checks whether a function belongs to the connection lifecycle, including connection establishment, disconnection, and heartbeats.

    max_bvlc()

    Returns the maximum BVLC message size accepted by the codec, in octets.

    max_npdu()

    Returns the maximum NPDU size advertised by the BACnet/SC implementation.

    nak(message, error, marker \\ 0)

    Builds a communication-class BVLC-Result NAK for the request. Returns nil for broadcasts and responses, which cannot receive a result.

    peer(arg)

    Extracts peer identity and size limits from a validated connection payload.

    random_vmac()

    Generates a Random-48 VMAC with the low nibble of the first octet set to two.

    response(request, function, payload \\ <<>>)

    Builds a response that uses the request message ID and addresses its originating VMAC when that address was present.

    unsupported_option(bvlc)

    Returns the marker of the first destination option that requires understanding and is unsupported, or nil when the destination options may be ignored.

    valid_vmac?(address)

    Checks that the value is a six-octet VMAC other than the reserved all-zero and all-ones addresses.
