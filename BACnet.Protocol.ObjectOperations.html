    BACnet.Protocol.ObjectOperations (bacstack v0.1.0-dev.2)

    View Source

    Shared operations for BACnet object structs.

    BACnet.Protocol.ObjectsMacro used to copy these functions into every object module. Object modules now delegate here and pass an BACnet.Protocol.ObjectsContract plus hook functions for the overridable steps (add_defaults/2, check_implicit_relationships/2, inhibit_object_check/4).

    Nothing in this module runs as a process. The functions are pure aside from the hooks the caller supplies.

    create/6 calls the hooks. add_defaults/3 and check_implicit_relationships/3 do not, so an object module can call them from super without looping.

    add_defaults(contract, properties, metadata)

    @spec add_defaults(BACnet.Protocol.ObjectsContract.t(), map(), metadata()) :: map()

    Merges compile-time defaults into properties.

    Local objects receive required defaults, intrinsic defaults, cov_increment, and init_fun properties. Remote objects receive only remote_defaults. This function does not call hooks.

    add_property(contract, object, property, value, hooks)

    @spec add_property(
  BACnet.Protocol.ObjectsContract.t(),
  struct(),
  atom(),
  term(),
  operation_hooks()
) ::
  update_result()

    Adds an optional property.

    Remote objects are rejected. Intrinsic properties cannot be added. A new priority array must leave slot 6 empty. On success, runs implicit relationships, propagation, and the inhibit hook.

    @spec remove_property(
  BACnet.Protocol.ObjectsContract.t(),
  struct(),
  atom() | non_neg_integer(),
  operation_hooks()
) :: update_result()

    Removes an optional property. Removing a property that is not present succeeds.

    Remote objects are rejected. Removing a stored unknown numeric property drops it from _unknown_properties and runs the inhibit hook.

    set_minimum_time_hold(contract, object, value, hooks)

    @spec set_minimum_time_hold(
  BACnet.Protocol.ObjectsContract.t(),
  struct(),
  term(),
  operation_hooks()
) ::
  update_result()

    Sets or releases the minimum-time hold on a local commandable object.

    The object's Present_Value rules validate the hold value. Pass nil to release it. BACnet.Protocol.ObjectExecution.BinaryState uses this operation to maintain slot 6 on commandable Binary Output and Binary Value objects. The inhibit hook runs when arbitration produces a changed object.

    set_priority(contract, object, priority, value, hooks)

    @spec set_priority(
  BACnet.Protocol.ObjectsContract.t(),
  struct(),
  1..16,
  term(),
  operation_hooks()
) ::
  update_result()

    Writes one slot of the priority array and refreshes present_value.

    Local commands and relinquishments at priority 6 return {:error, :write_access_denied}. Pass nil to clear the slot. The inhibit hook runs after arbitration, automatic feedback updates and validation.

    update_property(contract, object, property, value, hooks)

    @spec update_property(
  BACnet.Protocol.ObjectsContract.t(),
  struct(),
  atom(),
  term(),
  operation_hooks()
) ::
  update_result()

    Updates a property that is already present.

    Remote objects skip the intrinsic-property check. Propagation and the inhibit hook still run. Commandable present_value writes are rejected. Replacing a local priority array must preserve slot 6.

    @spec valid_reliability?(BACnet.Protocol.ObjectsContract.t(), struct(), term()) ::
  boolean()

    Checks a retained Reliability value against the object's property contract.

    A nil value represents an unselected or uninitialized Reliability input.

    @spec verify_properties(BACnet.Protocol.ObjectsContract.t(), map(), metadata()) ::
  {:ok, map()} | {:error, term()}

    Checks required properties, required_when, only_when, and forbidden_when.

    Remote objects only check required properties and their protocol revision.
