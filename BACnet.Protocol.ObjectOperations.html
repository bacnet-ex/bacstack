    BACnet.Protocol.ObjectOperations (bacstack v0.1.0-dev.2)

    View Source

    Shared operations for BACnet object structs.

    BACnet.Protocol.ObjectsMacro used to copy these functions into every object module. Object modules now delegate here and pass an BACnet.Protocol.ObjectsContract plus hook functions for the overridable steps (add_defaults/2, check_implicit_relationships/2, inhibit_object_check/1).

    Nothing in this module runs as a process. The functions are pure aside from the hooks the caller supplies.

    create/6 calls the hooks. add_defaults/3 and check_implicit_relationships/3 do not, so an object module can call them from super without looping.

    add_defaults(contract, properties, metadata)

    @spec add_defaults(BACnet.Protocol.ObjectsContract.t(), map(), metadata()) :: map()

    Merges compile-time defaults into properties.

    Local objects receive required defaults, intrinsic defaults, cov_increment, and init_fun properties. Remote objects receive only remote_defaults. This function does not call hooks.

    Remote objects are rejected. Intrinsic properties cannot be added. On success, runs implicit relationships, propagation, and the inhibit hook.

    set_priority(contract, object, priority, value)

    @spec set_priority(BACnet.Protocol.ObjectsContract.t(), struct(), 1..16, term()) ::
  update_result()

    Writes one slot of the priority array and refreshes present_value.

    A nil value clears the slot and is not type-checked. Feedback is copied from the present value when auto_write_feedback is set. This does not run the inhibit hook.

    update_property(contract, object, property, value, hooks)

  BACnet.Protocol.ObjectsContract.t(),

  atom(),
  term(),
  operation_hooks()

  update_result()

    Updates a property that is already present.

    Remote objects skip the intrinsic-property check. Propagation and the inhibit hook still run. Commandable present_value writes are rejected.
